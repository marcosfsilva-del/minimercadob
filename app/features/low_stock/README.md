# Feature `low-stock`

Implementação da funcionalidade de Estoque Baixo (Módulo 06 - Requisitos 016, 017 e 018).

## Regras
- Limite para estoque baixo: `LOW_STOCK_THRESHOLD = 5`.
- Produtos com estoque $\le 5$ recebem um selo de alerta visual no card.
- A página `/low-stock` lista apenas os produtos com estoque baixo.

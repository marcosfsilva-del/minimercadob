# Reposição de estoque

Tela para aumentar o estoque de um produto e registrar o movimento do tipo reposição.

- O usuário seleciona o produto e informa a quantidade.
- Ao confirmar, o estoque aumenta.
- A mesma operação grava um movimento com produto, tipo `REPOSICAO` e quantidade.
- Quantidade menor que 1 é recusada e não altera o estoque.
